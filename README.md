# Jasi Modern - 现代化补丁工具

基于Jasi Patcher v4.6技术的现代化Android应用重构项目。

## 技术栈升级

- Java → Kotlin
- Android SDK minSdk 14 → 24
- Support Library → AndroidX
- Xposed → LSPosed (更安全)
- 动态代码加载 → 现代化插件系统

## 核心功能

1. **应用许可证破解** - 绕过Google Play Licensing
2. **应用内购买破解** - 模拟Play Billing服务
3. **广告屏蔽** - 内置hosts文件
4. **Xposed模块支持** - 系统级Hook
5. **自定义补丁系统** - 动态DEX加载

## 安全增强

- TLS 1.3支持
- Android Keystore系统
- 强化字符串加密算法
- 反调试检测
